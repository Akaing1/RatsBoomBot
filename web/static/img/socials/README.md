# Social platform icons

YouTube, Discord, TikTok, X, Ko-fi, and Twitch SVGs are from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons),
distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Brand colors are applied to the original paths.

The VGen dark-background badge is from the
[official VGen brand assets](https://help.vgen.co/hc/en-us/articles/12884824880663-VGen-Brand-Assets),
[original image](https://help.vgen.co/hc/article_attachments/13004232167575).
It is used unchanged; see VGen's brand asset usage terms on that page.

The Throne light icon is from its
[official community brand kit](https://drive.google.com/drive/folders/1jaGvdCDEKJjuMwToljn6x4tlZq0_1EU2),
linked by the [Throne Help Center](https://help.throne.com/en/articles/15948420-how-do-i-add-throne-panels-and-logos-to-my-channel).
The original SVG is used unchanged.

The generic website globe is drawn in `shared/social_icon.html`.
