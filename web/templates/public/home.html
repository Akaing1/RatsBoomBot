Everything in one place

Tools viewers enjoy and streamers can actually use.

Every channel profile can have its own commands, messages, currency, redeems, and enabled features. Select a panel to explore its command catalog.

01

Personalized chat

Custom interactions, social links, timers, and community messages written for each channel.

Available commands

!hi [username]!choice <options>!kaboom [username] !stinky [username]!lucky [username]!smart [username] !height [username]!pp [username]!lurk!help !socials!socials discord!socials youtube !set game <game name>!set title <stream title>!setdiscord <url>!setyoutube <url>!timers [on|off]
02

Loyalty and redeems

Channel-specific currencies, viewer balances, games, daily check-ins, redeem history, and milestones.

Currency command

!currency [username]!currency leaderboard !currency gamble <amount|all>!currency duel <username> <amount> !currency duel accept!currency duel decline !currency add <username> <amount>!currency reset

“Currency” is replaced by the channel's configured command, such as !shards or !mews. Check-ins and other redeems are activated through Twitch channel points.

03

Viewer activities

Viewer queues, clips, raid tools, community leaderboards, and interactions designed around the stream.

Available commands

!open!close!join!leave!queue !next!remove <position>!clear !clip!clip short!startraid <channel>
04

Game integrations

Profile-aware League and Overwatch commands for builds, ranked statistics, registration, and community ladders.

League of Legends

!champs!champs <champion>!register <Riot ID> [region] !unregister!rank [chatter]!ladder

Overwatch

!ow!owrank!owrecord <win|loss>!owreset
05

Streamer dashboard

See stream status, check-ins, channel-point activity, social links, viewer queues, enabled features, and command help.

Dashboard tools

No chat command is required. Broadcasters sign in with Twitch to view live activity, manage enabled features, and browse their channel's exact command list.

06

Responsible moderation

Protected users, permission-aware commands, cooldowns, shoutouts, and detailed per-stream event logs.

Available commands

!so <username>!kamikaze <username>

Permission-sensitive actions are restricted to moderators or the broadcaster when appropriate.

The catalog shows what RatsBoomBot supports. Each channel receives its own configured subset, currency name, and channel-specific commands.
